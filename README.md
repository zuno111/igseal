# igSeal 봉인함

납품물을 암호화해 **보기 전용 단일 exe** 로 만드는 도구. 비밀번호가 없으면 못 열고, 지정한 날짜가 지나면 자동 삭제된다. 돈 안 주고 납품물을 계속 쓰는 것을 막는 용도.

## 전용 확장자 .igs (신규)
- 봉인물을 `.igs` 전용 파일로 출력. 우리 뷰어가 윈도우 HKCU 레지스트리에 확장자 핸들러로 자가등록(관리자 권한 불필요)해서, `.igs`는 더블클릭하면 우리 뷰어로만 열림. 다른 프로그램은 포맷을 몰라 못 엶.
- **자동 타이머 삭제**: 만료일 외에 "개봉 후 N시간 뒤 삭제" 타이머를 파일에 내장. 기한 지나면 뷰어가 열 때 그 .igs 자동 삭제.
- **이동 금지 바인딩**: 처음 연 PC/위치를 파일 트레일러에 써넣어(HMAC 보호) 복사·이동해도 따라감. 다른 PC로 복사(machine)하거나 다른 폴더·USB로 옮기면(path) 거부. 바인딩 정보 변조도 탐지.
- 한계: 바인딩은 뷰어가 확인·거부하는 방식(키 자체를 PC에 묶으면 제작 PC≠거래처 PC라 못 엶). 포맷을 작정하고 뜯는 건 못 막지만 일반 복사·이동은 차단.

## 구성물 (2개 exe)
- **igSeal-Packager.exe** (제작기) — 사장님이 씀. 폴더/파일 선택 + 비밀번호 + 만료일 → 봉인 exe 1개 생성.
- **igSeal-Viewer.exe** (뷰어 스텁) — 제작기에 내장됨. 직접 쓸 일 없음.

## 동작
1. 제작기로 파일을 봉인하면 `제목_봉인.exe` 1개가 나온다. 이 파일만 거래처에 전달.
2. 거래처가 더블클릭 → 비밀번호 입력 → 열람.
   - 문서/텍스트/이미지/PDF: 뷰어 내부에서 직접 열람(복사·추출 차단).
   - CAD/3D/영상 등 전문 포맷: 거래처 PC의 해당 프로그램으로 열고, 뷰어를 닫으면 임시파일 자동 삭제.
3. 지정한 날짜가 지나면 실행 시 봉인 exe 자신을 자동 삭제.

## 스크린샷·녹음 대응 (아날로그 홀)
화면에 띄우고 소리로 내보내는 이상, 스크린샷·녹음은 어떤 DRM도 100% 못 막는다(넷플릭스·멜론 포함). 그래서 "못 찍게"가 아니라 "찍어도 누가 흘렸는지 남게" 추적으로 대응한다.
- 이미지·PDF: 거래처명/날짜 **보이는 워터마크** 합성 → 스크린샷에 그대로 찍힘.
- 음악(WAV): **오디오 워터마크** — 거래처 식별 신호를 주기적으로 저음량 삽입. 녹음본에도 남아 유출처 특정 가능(ffmpeg 없이 표준 라이브러리).
- 내부 열람창: 윈도우 캡처 차단으로 스크린샷·녹화에 검게.
- 미납 시 이 추적 근거가 압박 수단이 된다. WAV 외 압축 오디오(mp3 등)는 현재 보이는 워터마크/캡처차단으로만 대응.

## 추가 보호 (제작기 "4. 추가 보호"에서 설정)
- **워터마크**: 거래처명·날짜 등을 열람 화면과 내보낸 임시파일(이미지·PDF·WAV)에 합성 → 유출 억제·추적.
- **최대 열람수**: N회까지만 열람 허용(로컬 기록 기준).
- **원격 폐기(킬스위치)**: 미납 시 원격으로 사용 중지/삭제. 아래 설정 참고.
- **화면 캡처 차단**: 내부 열람 창을 스크린샷·화면녹화에 검게(윈도우 기본 기능).
- 비밀번호 10회 오류 시 종료, 암호화 강도 상향(scrypt N=2^16).

## 오프라인 구멍 좁히기 (랜선 뽑고 여는 경우)
원격 폐기만으로는 인터넷 끊긴 PC를 못 막는다. 아래 두 옵션으로 좁힌다.
- **최초 1회 온라인 활성화 필수**: 처음 열 때 인터넷 확인이 돼야 열림. 랜선 뽑고 첫 실행 차단, 다른 PC로 복사해도 오프라인이면 못 엶.
- **오프라인 허용일(리스)**: 활성화돼도 정한 일수마다 인터넷 재연결 필요. 온라인에 붙을 때마다 로컬 기한 갱신, 그 사이 폐기하면 다음 갱신 거부.
- 한계: 한 번 활성화한 그 PC에서 리스 기간 안에는 오프라인 열람 가능. 리스를 1일로 잡으면 그 창이 하루로 좁아짐. (둘 다 원격폐기 URL 필요)

## 패키지 관리 (제작기 "패키지 관리" 버튼)
봉인한 패키지가 거래처·만료일과 함께 목록에 쌓인다. 각 건을 폐기/해제·만료연장 버튼으로 바꾼 뒤 "revoke.json 저장"을 누르면 Gist에 올릴 파일이 생성된다. Gist를 손으로 편집할 필요 없음.

## 원격 폐기 설정 (무료)
1. GitHub 로그인 → https://gist.github.com 에서 공개 Gist 하나 생성, 파일 내용:
   `{"revoked": [], "extend": {}}`
2. 저장 후 그 파일의 **Raw** 버튼 주소를 복사 → 제작기 "원격폐기 URL"에 붙여넣기.
3. 봉인하면 "패키지 ID"가 나옴. 메모해 둠.
4. 돈 안 주면: Gist를 열어 `"revoked": ["그 패키지ID"]` 로 수정 → 거래처가 다음에 실행하면 자동 삭제.
   결제되면: `"extend": {"그 패키지ID": "2027-06-30"}` 으로 만료일 원격 연장.
- 인터넷이 연결됐을 때 동작. 오프라인이면 봉인 시 정한 만료일로 작동.

## 보호 수준 (있는 그대로)
- 확실: 비밀번호 없으면 복호화 불가(비번=AES 키), 만료일 경과 시 자동 삭제, 원격 폐기, 시계 되돌림·헤더 변조 탐지, 내부 열람 캡처 차단.
- 한계: 전문 프로그램으로 여는 동안의 복사는 무료 방식으로는 100% 차단 불가(워터마크로 억제). CAD·영상 등 비이미지 포맷엔 워터마크 합성 불가. 메모리 덤프·역분석에 작정하면 뚫림(모든 DRM 공통).
